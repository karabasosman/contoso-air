## Scope of Work

### 1. Technology Stack Modernization

#### Node.js Upgrade
- ✅ Migrated from legacy Node.js version to **Node.js 22.x** (LTS)
- ✅ Updated Express framework to **version 5.1.0**
- ✅ Modernized all npm dependencies to latest stable versions
- ✅ Resolved compatibility issues and deprecated API usage

#### Package Updates
Key package updates implemented:
- `express`: 5.1.0 (with ES6 module support)
- `mongoose`: 8.15.0 (MongoDB driver)
- `mongodb`: 6.16.0
- `@azure/identity`: 4.9.1 (for Managed Identity)
- `axios`: 1.9.0
- `bootstrap`: 5.3.6
- `passport`: 0.7.0

### 2. Database Modernization

#### Azure CosmosDB Integration
- ✅ Implemented **MongoDB API 7.0** support

- ✅ Implemented repository pattern for clean architecture
- ✅ Added connection pooling and error handling

#### Docker Implementation
- ✅ Multi-stage Dockerfile for optimized builds

- ✅ Layer caching for faster builds
- ✅ Non-root user execution
- ✅ Health check configuration
- ✅ Environment variable support

**Dockerfile Highlights**:
```dockerfile
FROM node:20-alpine AS base
WORKDIR /usr/src/app
COPY package*.json ./
RUN npm ci --omit=dev
COPY . .
EXPOSE 3000
ENV NODE_ENV=production
RUN addgroup -S appgroup && adduser -S appuser -G appgroup
USER appuser
CMD ["node", "./bin/www"]
```

## Technical Architecture

### Application Structure
```
contoso-air/
├── src/web/
│   ├── app.js                 # Express application setup
│   ├── bin/www               # Application entry point
│   ├── routes/               # API endpoints
│   │   ├── auth.js          # Authentication routes
│   │   ├── book.js          # Booking routes
│   │   ├── flights.js       # Flight search
│   │   ├── purchase.js      # Purchase flow
│   │   └── receipt.js       # Receipt generation
│   ├── services/             # Business logic
│   │   ├── book.service.js  # Booking operations
│   │   ├── flights.service.js
│   │   └── date.service.js
│   ├── repositories/         # Data access layer
│   │   ├── book.repository.js
│   │   └── flights.repository.js
│   ├── views/                # Handlebars templates
│   ├── public/               # Static assets
│   ├── config/               # Configuration files
│   ├── data/                 # Mock data (airports, flights)
│   └── Dockerfile           # Container definition
├── infra/k8s/               # Kubernetes manifests
└── .github/workflows/       # CI/CD pipelines
```

### Data Flow
```
User Request → Express Router → Service Layer → Repository → CosmosDB
                                                  ↓
                                            Managed Identity Auth
```
